# ForgeKit

The Swift half of the ixOS application runtime. Your app's Rust core embeds
`forge-app` (the Rust half). ForgeKit gives the SwiftUI app what every app
needs and none should write:

- `ForgeHost`: owns the Rust core for the life of the process, opens it off
  the main actor, refuses a Rust library built for another contract version,
  runs the event loop, and exposes `changes` so views know when to re-read.
- `ForgeLifecycle`: reports the application lifecycle to the core.
- `ForgeRoot`: shows loading, ready and failed states.
- `withRustCancellation`: cancelling a Swift task cancels the work in Rust.
- `ForgeErrors`: presents any app's errors by their framework kind.
- `ForgeApp`: the contract types shared by every app (`AppPhase`,
  `ErrorKind`, `RuntimeEvent`, `RuntimeEvents`, `Cancellation`), as
  generated by UniFFI from `forge-app`. `import ForgeKit` brings them in.

It also ships **ForgeUI**, the ixOS design system: theme tokens (colours
for light and dark, spacing, corner radii) and styles and components built on
SwiftUI's own controls: button and field styles, `ForgeField`, `ForgeCard`,
`ForgeRow`, `ForgeBadge`, `ForgeStatus`, `ForgeStateView`,
`ForgeDetailHeader`. `import ForgeUI` needs no Rust core, so any SwiftUI app
can use it. Guide: [docs/forgeui.md](https://github.com/GeneralKnowledge/ixOS/blob/main/docs/forgeui.md).

And **ForgeAppKit**, optional application patterns on ForgeUI: alerts and
confirmations as model values (`ForgeAlert`), destinations as one optional
enum (`.forgeSheet`), load state (`ForgeLoad`, `ForgeLoadView`), submission
state for busy buttons (`ForgeSubmission`) and form errors by field
(`ForgeFieldErrors`). It needs no Rust core either. Guide:
[docs/forgeappkit.md](https://github.com/GeneralKnowledge/ixOS/blob/main/docs/forgeappkit.md).

```swift
.package(url: "https://github.com/GeneralKnowledge/ForgeKit.git", exact: "<version>")
```

Use the same release on both sides: your Rust crate takes `forge-app` from
git at the ixOS commit this release's `RELEASE` file names. `forge init`
writes both pins for you.

## Where it is made

This repository holds releases only. ForgeKit is developed in
[ixOS](https://github.com/GeneralKnowledge/ixOS) under `forgekit/`, and
`scripts/forgekit.sh release` copies it here and tags it. That script also
checks that the Rust and Swift contract versions agree. Don't open changes
here; change ixOS. `RELEASE` names the ixOS commit each release came from.
